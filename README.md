# pqblocks.github.io

Official documentation site source for PQBlocks (https://pqblocks.github.io).
Built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

## Local Development

```bash
pip install mkdocs-material
mkdocs serve
```

## Structure

- `docs/index.md`: Homepage, architecture, transition map
- `docs/packages/`: Catalog of the 26 PQBlocks packages
- `docs/recipes/`: End-to-end practical tutorials (FastAPI, JWT, TLS, CBOM)
- `docs/security/`: Verification reports standard and cryptographic limits
- `docs/ai/`: Guide for AI coding assistants (MCP server, Claude skills, Cursor rules)
- `docs/llms.txt`: Flat text index for LLM crawlers
