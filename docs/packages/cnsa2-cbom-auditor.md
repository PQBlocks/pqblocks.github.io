## What is pqblocks-cnsa2-cbom-auditor?

CycloneDX 1.6 Cryptographic Bill of Materials (CBOM) generator, validator, and delta comparator enforcing NSA CNSA 2.0 and NIST FIPS 203/204/205 post-quantum standards.

## Quickstart

!!! success "Executed, not just written"
    This is the quickstart from the package README. It was run against the package source when this page was generated.

```javascript title="quickstart.js"
import { scanToCbom, verifyCbom } from '@pqblocks/cnsa2-cbom-auditor';

// Audit target directory and synthesize CycloneDX 1.6 CBOM
const { bom, summary } = await scanToCbom('./certs');
console.log('Inspected assets:', summary.total);
console.log('CycloneDX spec version:', bom.specVersion);

// Validate CBOM against CycloneDX 1.6 schema
const report = verifyCbom(bom);
console.log('Schema valid:', report.valid);
```
