# :material-transit-connection-variant: Interoperability

<p class="pqb-lead">Wire formats, JOSE, X.509/CSR and TLS hybrid groups that carry larger post-quantum keys, ciphertexts and signatures through real protocols.</p>

<div class="grid cards" markdown>

-   __[pqblocks-csr-pop](csr-pop.md)__

    ---

    ML-KEM (FIPS 203) PKCS#10 Certificate Signing Request (CSR) generator with RFC 9883 Proof of Possession (PoP).

    `pip install git+https://github.com/PQBlocks/mlkem-csr-pop`

-   __[pqblocks-jwe](jwe.md)__

    ---

    Compact five-part wire format, with a serializer and structural parser, for hybrid ML-KEM-768 + X25519 JWE-style tokens; it performs no encryption itself.

    `pip install git+https://github.com/PQBlocks/hybrid-jwe`

-   __[pqblocks-tls-interop](tls-interop.md)__

    ---

    TLS 1.3 hybrid key exchange (X25519MLKEM768 / RFC 10024) endpoint probe, downgrade detector, and key material validator.

    `pip install git+https://github.com/PQBlocks/tls-hybrid-interop`

-   __[pqblocks-wire](wire.md)__

    ---
